# Sukho Thai Kitchen website

Files
- index.html : the page text (opening hours, address, phone, menu wording)
- style.css : colours, fonts and layout
- storefront.jpg : the main photo (upload a new file with the same name to replace it)

Edit text: open index.html on GitHub, click the pencil icon, change the words, then press Commit changes.
The site updates a minute or two later.
